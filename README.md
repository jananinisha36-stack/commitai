# CommitAI – Intelligent Commitment Detection and Automated Reminder System

## Overview
CommitAI analyzes text messages to detect commitments (promises to complete a task), extracts the task and deadline, and automatically tracks it as a reminder with status updates (Pending / Completed / Overdue).

## Features
- Commitment detection using keyword/pattern matching
- Task and deadline extraction from natural language messages
- Automatic reminder creation with status tracking
- Dashboard to view all tasks and their status
- Data persistence using browser localStorage

## Tech Stack
- HTML, CSS, JavaScript (Frontend)
- Browser localStorage (Data storage)

## How to Run
1. Clone this repository
2. Open `database-integration/index.html` in any browser
3. Type a message like "I will submit the report tomorrow"
4. Click "Submit Message" to see it tracked on the dashboard
